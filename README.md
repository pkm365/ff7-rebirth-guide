# FF7 重生图文攻略

《最终幻想7：重生》自制中文图文攻略（单页站）。

## 在线看

推送后在仓库 Settings → Pages 里打开 GitHub Pages（选 main 分支 / root），即可手机随时看。

## 文件说明

- `index.html` — 攻略页面本体
- `assets/imgNN.txt` — 图片以纯文本存放（首行为 MIME 类型，后为 base64），页面内的 JS 加载器会按需取回拼成图片显示。
  这样存放是因为图片二进制无法经 API 直接上传；内容与原站一致。

## 更新

攻略在 Muse 里维护，每次大更新后重新导出并 push 本仓库。
