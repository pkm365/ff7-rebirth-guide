## 七名角色配装模板

选择角色查看定位、魔晶石与操作要点。模板强调“为什么这样配”，不把唯一毕业装写死。

### Cloud · 主控万金油

格挡切 Punisher 反击；先用低成本技能维持 ATB，再用属性弱点造压力。

**魔晶石**：Healing、Elemental、First Strike、ATB Assist、Precision Defense、HP Up

#### 前期

Assess＋Healing＋一组敌人弱点元素。

#### 中期

Elemental＋Fire and Ice 放武器，First Strike 快速开局。

#### Hard

Chakra、Steadfast Block、HP Up；把 MP 留给复活和关键魔法。

### Barret · 远程坦克

Overcharge 循环稳定产 ATB；Steelskin＋Lifesaver 接管团队伤害。

**魔晶石**：Healing、Revival、Provoke、HP Up、Vitality Up

::: tip 操作核心

长按射击结束后立刻按 Overcharge，可取消收招并持续积攒 ATB。Boss 飞空或近战难贴身时优先上 Barret。

:::

### Tifa · 力竭倍率引擎

两层 Unbridled Strength 预备；敌人力竭后 True Strike＋Rise and Fall＋Omnistrike 快速抬倍率。

**魔晶石**：Strength Up、First Strike、ATB Assist、Chakra、HP Up

::: tip 300% 奖杯

先攒 2 ATB 和两层秘技，力竭后连续 True Strike，再释放强化普攻；队友此时不要过早打死目标。

:::

### Aerith · 魔法炮台 / 主奶

Arcane Ward 让攻击魔法双重施放；Radiant Ward 提升生存与普攻 ATB。

**魔晶石**：Magnify、Healing、Magic Efficiency、Time、Magic Up、MP Up

::: tip Hard 生存

Soul Drain 是稀缺的主动回 MP 手段。不要让 Aerith 每场小怪战都放高阶魔法。

:::

### Red XIII · 格挡反击 / 自愈前排

精准格挡堆 Vengeance 槽，开启 Vengeance Mode 后靠吸血与高速连击续航。

**魔晶石**：Precision Defense、Steadfast Block、Chakra、HP Up

::: tip 团队价值

Golden Collar 的能力可消耗复仇槽群疗；面对连续战时，他能把 MP 压力从 Aerith 身上移走。

:::

### Yuffie · 全元素远程 / ATB 发电

Elemental Ninjutsu 无 MP 切弱点，Doppelgänger 复制技能；远近切换适应所有战场。

**魔晶石**：Elemental、Enemy Skill、HP Absorption、Precision Defense、ATB Assist

::: tip 弱点机器

先给手里剑附魔，再用远程普攻与忍术制造压力；Doppelgänger 之后释放高收益 ATB 技。

:::

### Cait Sith · 控场辅助 / 莫古坦克

先召唤 Moogle，让本体保持安全距离；以 Time、Barrier、Healing 填补团队缺口。

**魔晶石**：Time、Barrier、Healing、Luck Up、HP Up

::: tip 定位

伤害带随机性，不适合当唯一输出；回声扩音器（Resounding Megaphone）的莫古力地雷（Moogle Mine）适合中期控场。

:::
