## 好感度与金碟约会

羁绊来自对话选项、对应角色支线评价、首次协同技能/能力，以及少数主线选择。L1 可看笑脸颜色，通关后 Play Log 显示精确百分比。

### 锁定目标的做法

1. 优先做目标角色头像对应支线，并争取最高评价。
2. Cloud 与目标角色的协同技能、协同能力各至少首次使用一次。
3. Ch6 选择帮助目标所在小组；泳装风格尽量匹配。
4. 暂缓其他角色的后期支线，等 Ch12 约会后再补。

### 两次约会

**Ch8**：初访金碟的夜间游园。

**Ch12**：Loveless 歌剧＋Skywheel 摩天轮正式约会。

对象包括 Aerith、Tifa、Barret、Red XIII、Yuffie；无人达标时出现 Cid＋Vincent＋Cait Sith 组合。

::: tip 普通 / 亲密版

羁绊达到第 4 阶触发普通约会，第 5 阶为亲密版。想看全路线无需重开：通关后可在额外设置中指定 Ch8 / Ch12 对象与约会版本。

:::
