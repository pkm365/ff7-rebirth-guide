## 小游戏：该练什么，不该硬耗什么

金碟只是其中一部分。全成就会要求多项最高级奖励，建议首见只过门槛，Ch12 装备和等级齐全后再刷高分。

![Cloud 一行进入灯火辉煌的金碟游乐园](/images/img00.jpg)

| 项目 | 关键技巧 | 全成就关联 |
| --- | --- | --- |
| **3D Brawler** | 先辨左右手，再辨直拳/钩拳/上钩；可在对手起手瞬间暂停读姿势。 | 击败 Sephiroth |
| **Chocobo Racing** | 弯前留耐力，出弯再加速；Gold Cup 前先清低级赛事。 | 20 场全胜 |
| **Fort Condor** | 先按兵种相克守线，英雄单位留作反推；Hard 关卡重视费用曲线。 | Protorelic |
| **Gears and Gambits** | 不是拼等级，而是按敌人弱点写机器人行动优先级。 | Protorelic |
| **Piano** | 先降音符速度熟谱，再提速；只需 6 首拿评价奖励。 | Piano Virtuoso |
| **Cactuar Crush** | 先辨物理/魔法仙人掌；Yuffie 用忍术切属性，Aerith 提前铺 Ward。 | Johnny 收藏 |
| **Glide de Chocobo** | 不要立刻俯冲，先利用上升气流攒高度；训练 1 的 3600 分给 Yuffie 武器。 | 支线/武器 |
| **Crunch-Off** | 跟节奏而非看动画，半按与全按提示要分清；失误后不要抢拍追赶。 | Johnny 收藏 |
| **Galactic Saviors / G-Bike** | 背路线比反应更重要；优先高分目标与连击维持。 | 金碟收藏 |
| **Run Wild / Jumpfrog / Dolphin Rush** | 首轮先学规则，后续再冲评级；多数可在章节选择补做。 | 区域奖励 |
