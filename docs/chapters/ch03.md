*第 3 章 · 双队教学*

矿山路线本身不难，难点是分队后魔晶石会不会放错人。每次切队都先把洞察、治疗和当前首领的弱点属性搬过去。

克劳德 / 蒂法 / 爱丽丝 · 巴雷特 / 赤红十三 · 两场首领战

::: tip 新手提示

**新手先做**

这一章会强制分两队，**魔晶石不会自动复制**。每次画面切队，第一件事都打开装备菜单：把洞察、治疗和当前弱点属性交给正在操作的队伍。迷路时跟着墙面黄色攀爬漆、轨道和同伴站位走。

:::

## 区域入口 → 矿内楼层 · 秘银矿山

先在区域地图确认矿山位于格拉斯兰与珠诺之间的山口；进矿后再切“地点地图”，用左侧楼层列表确认自己所在层。

![区域地图上以红圈标出的秘银矿山入口](/images/img09.jpg)
**大地图：矿山入口**
秘银矿山在格拉斯兰东北侧的山口，是前往珠诺的必经主线入口。沿黄色主线标记走，不需要绕去周围世界报告。

![秘银矿山下层地点地图，右侧黄色圆圈标出目标通道](/images/img10.webp)
**具体楼层：矿井下层**
矿内有多层。看左侧列表切换楼层；黄色圈一侧是目标通道。若标记看起来“就在旁边”却到不了，通常是你在错误楼层。

**路线**：格拉斯兰东北山口 → 矿山入口 → 克劳德队下层路线 → 路德 / 伊莉娜 → 巴雷特队矿车路线 → 秘银魔像

### 1 · 克劳德队开局

分队后先暂停整理魔晶石。起点前方岔路别急着下坡，先走右侧拿魔晶石成长加速（AP Up）。下层遇小型爬虫用火，遇水晶螃蟹用冰；先洞察再记弱点。

### 2 · 不漏蒂法武器

越过第一批敌人后沿主路找紫箱，里面是蒂法的新手套（Sylph Gloves）。立刻给蒂法装上，并把能把敌人打上天的技能（Reverse Gale）放入快捷栏练熟练度。上层巨怪可以绕；要打就防住棍击，出现“压力”再反击。

### 3 · 矿车与扶梯

第一辆矿车是清路：从后方推开。遇断梯时别找开关，把矿车推到金属结构正下方，当作脚踏爬上去。休息点就是双人首领战前的信号：风属性给克劳德，雷属性给爱丽丝或蒂法。

### 4 · 切巴雷特 / 赤红十三

画面切换后别立刻跑：休息点旁紫箱拿赤红十三的新项圈（Renegade's Collar），再把洞察和治疗转给这队。史莱姆怪对物理攻击抗性高，巴雷特普攻只用来积攒能力槽，真正伤害交给火焰魔法。

### 5 · 水路与轨道岔口

攀爬大厅先看右侧水路，沿路到东南死路拿魔力上限提升（MP Up）。到轨道开关时，先保持初始方向推车去侧台拿防弹背心；拿完返回扳开关，再推到主路出口。

### 6 · 巨像战前准备

放下两架梯子后先爬右梯，开 1,000 Gil 宝箱。最终休息点旁地面有雷属性魔晶石，至少给巴雷特装上；赤红十三带治疗，避免两人都没法续航。

![秘银矿山内巴雷特和赤红十三站在轨道矿车旁](/images/img11.jpg)
**认路照片 1 · 矿车用途**
矿车不是载具。看到断梯或高台时，从车后推到结构正下方；看到轨道开关时，先检查支路奖励再改轨。

![菜单里显示蒂法的新手套与武器能力](/images/img12.jpg)
**认物照片 2 · 蒂法的新手套**
菜单英文名是 Sylph Gloves，武器能力是 Reverse Gale。新武器不是只看攻击力：先用到熟练度满，能力就会永久保留。

## 双队装备分配

- **克劳德队**：风、雷、治疗、洞察。爱丽丝铺魔法阵，克劳德 / 蒂法负责打断敌人并推高力竭条。
- **巴雷特 / 赤红十三队**：雷、火、治疗、洞察。雷留给秘银魔像，火用来清抗物理的史莱姆怪。
- **容易漏**：成长加速、蒂法手套、赤红十三项圈、魔力提升、防弹背心、首领战门口的雷属性魔晶石。

## 两场首领战分别这样准备

- 路德 + 伊莉娜：克劳德带风属性，爱丽丝或蒂法带雷属性；至少一人带治疗，三人都装好常用能力快捷键。
- 秘银魔像：巴雷特带雷属性和洞察，赤红十三带治疗。进入战斗前回满魔力，因为本队只有两人。
- 锁定后按切换目标可在“本体 / 头 / 右臂 / 脊柱”之间换目标；看屏幕上方名称，别凭镜头猜正在打哪里。

### 路德 + 伊莉娜

- 开场先洞察两人；锁定伊莉娜先打，她血量更低、招式更快，先减员会轻松很多。
- 伊莉娜弱雷：她停下来准备招式时放雷魔法（Thunder）。出现“压力”后，用蒂法的力竭打击（Focused Strike）或克劳德的力竭突刺。
- 路德弱风：伊莉娜倒地后改锁路德，用风魔法制造压力；他防御时别连续砍，绕侧面或等招式结束。
- 二人开始连携、地面出现攻击轨迹时先跑开；爱丽丝站远处治疗，不要三人挤在一起。

### 秘银魔像

- 开场洞察后切巴雷特，按切换目标锁“头部”；用射击攒能力槽，再用雷魔法或爆发射击（Maximum Fury）打头。
- 头部破坏后才切本体输出。赤红十三主要负责防御，格挡充满复仇槽后再开启复仇模式（Vengeance Mode）。
- 后半长出右臂与脊柱：先破坏右臂减少挥击，再拆脊柱；雷魔法优先留给这些部位。
- 地面出现红色落点就持续移动，不要站着放长动作技能。

::: tip 两人战的安全循环

主控巴雷特远处射击 → 有 1 格能力槽就看赤红十三血量 → 需要时切赤红十三用治疗 → 切回巴雷特锁部位放雷。别让两人的能力槽同时见底，永远留一格给治疗。

:::
