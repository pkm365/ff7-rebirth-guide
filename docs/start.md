## 先掌握这五件事

《重生》的关键不是“练到碾压”，而是看懂敌人的弱点与状态，再把能力用在正确时机。下文一律先写中文用途，英文只放在括号里，方便你和游戏菜单对照。

### 先看弱点，再输出

*洞察（ASSESS）*

新怪第一次见面先用“洞察”，看看它怕什么、怎样才能进入压力状态。

### 切人就是加速

*能力槽（ATB）*

角色普攻时会积攒蓝色能力槽。电脑控制的队友积攒较慢，所以要轮流操作。

### 敌人倒地再爆发

*力竭（STAGGERED）*

敌人进入力竭后会受到更多伤害。此时再用高伤害技能、魔法和极限技。

### 困难难度要节省

*魔力（MP）*

困难难度不能用道具。普通战斗尽量用祈祷、气卦等不消耗魔力的恢复手段。

### 新手常见战斗用语

- **洞察（ASSESS）**：花 1 格能力槽，查看敌人的弱点和压力条件。
- **能力槽（ATB）**：生命条下方的蓝色分段槽；使用技能、魔法和道具都要消耗它。
- **压力（PRESSURED）**：敌人暂时站不稳。看到这个字样，就改用能快速增加力竭条的技能。
- **力竭（STAGGERED）**：敌人倒地且受到的伤害增加。这才是使用强力招式的最佳时机。
- **高威力跳斩（BRAVER）**：克劳德的重击招式；适合在敌人力竭后用来打伤害。
- **力竭突刺（FOCUSED THRUST）**：伤害不是重点；敌人处于压力状态时使用，能很快填满力竭条。

### 战斗循环

**洞察 → 攻击弱点 → 让敌人进入压力状态 → 用力竭类技能推满力竭条 → 敌人倒地后用强招收尾。**

### 技能熟练

拿到新武器就装备，完成其熟练条件。熟练后技能永久保留，无需继续带该武器。

### 开放世界节奏

不必每到新区就清空地图。优先塔、陆行鸟、召唤水晶；第 12 章再集中扫尾最舒服。
