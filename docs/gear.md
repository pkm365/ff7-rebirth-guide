## 武器、防具与饰品

紫色宝箱就是武器。最重要的不是面板，而是先把每把武器能力练满，永久加入技能库。

| 角色 | 关键武器 / 获取 | 用途 |
| --- | --- | --- |
| **Cloud** | Umbral Blade（Ch8）/ Igneous Saber | Prime Mode 改变强攻循环；Igneous Saber 偏高伤与槽位。 |
| **Barret** | Fafnir Rifle（Ch9 支线）/ Battle Cry | Point Blank 近身爆发；Battle Cry 强化 Overcharge 节奏。 |
| **Tifa** | Dragon Claws（Ch8 Desert Rush Rank 3）/ Jarngreipr | Starshower 后接高伤技能；True Strike 专注力竭倍率。 |
| **Aerith** | Ceremonial Staff（Ch10）/ Gambanteinn | ATB Ward 是团队加速核心；终盘重视魔攻与槽位平衡。 |
| **Red XIII** | Golden Collar（Ch9）/ Brisingamen | 消耗复仇槽群疗；Brisingamen 物魔均衡。 |
| **Yuffie** | Crescent Sickle（滑翔训练 3600 分）/ Bird of Prey | 精准防御向与 Doppelgänger 核心。 |
| **Cait Sith** | Resounding Megaphone（Ch9）/ Golden Megaphone（Ch11） | 莫古力地雷（Moogle Mine）控场；黄金扩音器（Golden Megaphone）侧重魔攻与 8 槽。 |

### Cetran Bracer

42 物防 / 魔防的终盘防具，优先给主控或最常吃伤的角色。

### Genji Gloves

突破 9999 伤害上限，适合高阶魔法或极限爆发。

### Gotterdammerung

开场极限槽全满并自动回充。来自高难模拟战，是 Hard 推图强力加速器。
